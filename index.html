Clear methods.
Responsible insights.

The project uses the supplied ev_market_test.csv file and Tableau Public.

01 / Data source

Supplied EV test dataset; not independently verified as representative real-world market data.

02 / Preparation

Missing sales or ratings are not assumed to be zero.

03 / Interpretation

Country and battery counts represent dataset records, not factory output or verified market share.

04 / Limitations

Model-year grouping is not necessarily transaction-year sales. Correlation does not prove causation.
